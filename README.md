# The Upper Room — Secret Code Challenge

A standalone, celebration-powered Next.js website styled with the authentic **The Upper Room** palette and branding.

## 🌟 Features
- **Shared Brand & Palette**:
  - Background: `#FCF8F2` (Warm Sand / Cream) with sacred Upper Room background
  - Primary: `#416047` (Forest Green)
  - Secondary: `#D97746` (Terracotta)
  - Celebration Gold: `#E5A93C`
- **Secret Code Validation**:
  - Target Word: `Nehemiah` (case-insensitive & trimmed)
  - Error state with micro-interaction card shake and sound feedback
  - Expandable historical hint
- **Marvelous Celebration & Win Experience**:
  - 🎆 Multi-stage canvas confetti burst, side cannons, and star fireworks
  - 🎺 Web Audio API synthesized victory arpeggio fanfare (no external audio files needed!)
  - 🏆 Radiant spinning celestial aura & pulsating golden card
  - ✨ Shimmering `NEHEMIAH` typography with Biblical inspiration (Nehemiah 2:20 & 8:10)
  - 🔄 Replay celebration, copy victory message, or try another code

## 🚀 Running Locally
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deploy to Vercel
1. Initialize or push this folder (`ur-secret-code`) to your GitHub account:
   ```bash
   git add .
   git commit -m "feat: initial release of secret code challenge"
   git branch -M main
   git remote add origin https://github.com/<your-username>/ur-secret-code.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com/new).
3. Import the repository `ur-secret-code`.
4. Click **Deploy**! (Zero extra configuration required).
